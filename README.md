# TERRA-Webzine-
Revista digital estática sobre aventura, naturaleza y vida sostenible. Construida con HTML5, CSS y JavaScript.

# Características
-  Uso de CSS Grid y Flexbox para el Layout
- Formulario de registro con validación en tiempo real e indicador de fuerza 
  de contraseña

# Tecnologías
- HTML5 
- CSS ( Grid, Flexbox.) 
- JavaScript ( Validacion del formulario de registro en login.html)

# Estructura del Proyecto
- assets        # Imágenes del proyecto
- index.html       # Página principal de la revista
- login.html       # Formulario de registro
- style.css        # Estilos de la revista
- login.css        # Estilos del formulario
- script.js        # Validación del formulario de registro
